# Athletiq (Android test build)

Test build of the Athletiq app for Android. Not on Google Play yet.

## Download
Latest APK: https://github.com/SgodoNkuna/athletiq-android/releases/latest/download/Athletiq-test.apk

## Install
1. Open the link on your Android phone and download the file.
2. Tap it. If asked, allow "Install unknown apps" for your browser or Files app.
3. Open Athletiq and sign in. Your account and data are stored in the Athletiq database and are still there next time you open the app.

## Steps (optional)
Athletiq can read your daily step count from Health Connect (steps only, nothing else), or from the phone's own step sensor if you prefer. You choose in the app and can turn it off and delete the data at any time.

## Notes
- Minimum Android 8.0.
- This is a test build: please report anything odd.
- The app loads the live Athletiq site, so most updates arrive without a new APK.
